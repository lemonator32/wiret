## Conventions

- Every file has YAML front matter (`title`, `document_type`, `source` where applicable, `formatted`).
- One H1 per file; a linked **Contents** list follows the introduction.
- Files marked *Reference article with extended analysis* contain a Wikipedia-derived Part I and a clearly labelled *Extended Analysis* section that is not Wikipedia text.
- Math uses `$…$` / `$$…$$`; code blocks carry language tags; tables use compact pipe syntax.
- Citations that survive as links are kept; unlinked source chips from the original export appear as *Source: …* notes.
